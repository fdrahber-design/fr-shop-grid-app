# FR SHOP GRID App

Official Android and Windows application wrapper for **FR SHOP GRID ERP**.

## Login and roles

The application opens the production login at https://frdevelopers.com/login. The existing ERP authentication automatically routes Super Admin, Shop Administrator, and Staff accounts to their permitted workspace.

## Build outputs

GitHub Actions creates:

- Android debug APK (manual installation)
- Windows portable EXE

Open the latest **Build FR SHOP GRID installers** workflow run and download its artifacts.
